# WPM Portfolio Editorial

Portfólio independente de Wallace Phillip Maclayne, com identidade editorial e estudos de caso.

## Estrutura

- `index.html`: home, trabalhos, sobre, prática, método e contato.
- `work/`: estudos de caso.
- `about.html`: perfil e trajetória.
- `contact.html`: canais de contato.
- `assets/style.css`: sistema visual.
- `assets/site.js`: menu mobile, ano e revelações.

## Rodar localmente

```bash
python3 -m http.server 8080
```

Abrir `http://localhost:8080`.

## Publicação

Site estático para GitHub Pages, branch `main`, raiz do repositório. Não requer build.

## Conteúdo

Os textos foram escritos a partir do perfil e dos registros reais dos projetos. Números de resultado têm origem nos registros do projeto MacAgents Hermes e nos dados publicados dos outros cases. Nenhum dado pessoal sensível é usado.
